# 🧰 Toolbox — Browser Extension

11 essential productivity tools in one Chrome extension.

## Tools
- 📝 Notepad — persistent notes across tabs
- ✅ Todo — quick task manager
- ⏱️ Pomodoro — focus timer with custom duration
- 🔢 Word Counter — words, chars, read time
- 🖊️ Highlighter — highlight text on any page
- 🗒️ Sticky Notes — draggable notes on any page
- 🎨 Color Picker — sample any color from any page
- 📏 Ruler — measure pixel dimensions on page
- 📸 Screenshot — visible and full page capture
- 📖 Reader Mode — clean reading view
- 🖼️ Image Downloader — find and download page images

## Install locally
1. Clone this repo
2. Open Chrome → chrome://extensions
3. Enable Developer Mode
4. Click Load Unpacked → select this folder

## Built with
Vanilla JavaScript, Chrome Extensions Manifest V3, Chrome Storage API
